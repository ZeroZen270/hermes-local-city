Hosted option — Nous Portal free tier (LongCat 2.5)

Local stays the default. To use Meituan's LongCat 2.5 free via Nous Portal instead, put this in config.yaml and export a key from portal.nousresearch.com (the key is read from the environment, never stored in config):

llm:
  provider: nous-longcat   # model: meituan/longcat-2.5:free, 1M context
  api_key_env: NOUS_API_KEY

Free availability, quotas and balance requirements are Nous's to change — treat the free tier as opportunistic, never a dependency. If the endpoint doesn't answer, serve falls back to the demo brain and local work is unaffected. Details in the README section linked below.

QUICKSTART

cd hermes-local-agent
python -m hermes_local                  # interactive REPL
python -m hermes_local "summarize my notes"   # one-shot task
python -m hermes_local --info           # resources / ladder / embedding status
python -m hermes_local serve --mock     # bridge + city + this portal
python tests/run_tests.py               # test suite (mock LLMs, no GPU)

URLs once serving: city at /, this portal at /portal, JSON-lines socket for engines on port 8766.
